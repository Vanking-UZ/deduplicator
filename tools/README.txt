fpcalc.exe (Chromaprint) — для функции «Похожая музыка»
========================================================

Похожая музыка определяется по аудио-отпечаткам Chromaprint через внешнюю утилиту fpcalc.exe.
Это единственная внешняя бинарная зависимость приложения (по ТЗ — поставляется в комплекте).

Куда положить:
  1) Рядом с приложением:  <папка приложения>\fpcalc.exe
  2) Или в эту папку:      tools\fpcalc.exe  (копируется в вывод сборки)
  3) Или указать полный путь в приложении: экран «Настройки» → «Путь к fpcalc.exe».

Где взять:
  Официальные сборки Chromaprint (проект AcoustID):
  https://acoustid.org/chromaprint  →  раздел загрузок, архив для Windows (chromaprint-fpcalc-*-windows-x86_64.zip).
  Из архива нужен только fpcalc.exe.

Проверка:
  В приложении на экране «Настройки» статус покажет «fpcalc найден — аудио-сверка доступна».

Без fpcalc приложение полностью работоспособно; недоступен только пункт глубины
«+ Похожая музыка» (поиск точных копий аудио по содержимому работает в любом случае).
