Генератор иконки приложения
===========================

app.ico и app-icon-256.png в src/Deduplicator.App/Assets сгенерированы из этого
небольшого инструмента (рисует «сквиркл»-плитку с глифом-дубликатом на ImageSharp.Drawing
и собирает многоразмерный .ico: 16/32/48/64/128/256).

Перегенерировать:
  dotnet run --project tools/icon -c Release -- "<путь к папке Assets>"
  (по умолчанию пишет в D:\projact\src\Deduplicator.App\Assets)

Нужен только при изменении дизайна иконки; в обычной сборке не участвует.
